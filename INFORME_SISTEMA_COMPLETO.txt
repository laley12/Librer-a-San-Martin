1. MÓDULOS DEL SISTEMA
--------------------------------------------------------------------------------
El sistema consta de 8 módulos principales accesibles desde la plataforma web
(Desktop) y la aplicación móvil PWA:

  1. Dashboard (Inicio)  🏠  Resumen general con KPIs de ventas, stock crítico,
                              gráficos estadísticos y accesos rápidos a módulos.
  2. Ventas              🛒  Punto de venta (POS), gestión de tickets, flujo
                              de caja y emisión de comprobantes.
  3. Inventario          📦  Catálogo de productos, control de stock,
                              categorías y administración de precios.
  4. Compras             📥  Gestión de proveedores, registro de adquisiciones
                              y control de pedidos.
  5. Usuarios y Roles    👤  Gestión de usuarios, asignación de roles,
                              presencia en tiempo real (🟢/⚪) y seguridad
                              con clave maestra.
  6. Reportes            📊  Indicadores clave, comparativas financieras y
                              gráficos de rendimiento del negocio.
  7. Perfil              👤  Autogestión del perfil del usuario logueado
                              (foto, nombre, correo).
  8. Auditoría           📋  Historial consolidado de cambios y operaciones
                              realizadas en el sistema.

Navegación Móvil PWA (movil.html):
  - Barra inferior con 4 botones: Inicio · Venta · Productos · Perfil
  - Soporte para botón físico "Atrás" del dispositivo (popstate)
  - Service Worker activo para uso offline parcial
  - Instalable como aplicación en el dispositivo

7. ARQUITECTURA TÉCNICA
--------------------------------------------------------------------------------

FRONTEND / PWA:
  • HTML5, Vanilla JavaScript (ES Modules), CSS Vanilla
  • Service Worker PWA (sw.js) con versionamiento de caché (lsm-v42)
  • Archivos principales:
    - index.html          → Página principal (Desktop)
    - movil.html          → Página optimizada para móvil
    - manifest.webmanifest→ Configuración PWA
    - sw.js               → Service Worker con caché versionado
  • Assets:
    - app.js              → Router SPA, navegación, popstate, UI principal
    - data.js             → Repositorio de datos, Supabase client, broadcast
    - ui.js               → Componentes de interfaz reutilizables
    - supabase-client.js  → Cliente Supabase configurado
    - confetti.min.js     → Animaciones de confetti
  • Vistas (web/assets/views/):
    - dashboard.js        → Panel de inicio con KPIs y gráficos
    - ventas.js           → Módulo punto de venta
    - inventario.js       → Gestión de productos y stock
    - compras.js          → Gestión de compras y proveedores
    - usuarios.js         → Gestión de usuarios, roles y presencia
    - reportes.js         → Módulo de reportes y estadísticas
    - perfil.js           → Autogestión del perfil del usuario

BACKEND / APIs (Serverless Vercel Node.js):
  Directorio: web/api/

  • _lib.js               → Funciones auxiliares compartidas:
                             - Hashing scrypt de contraseñas/PINs
                             - Emisión de tokens Supabase Auth
                             - Rate limiting y validaciones
  • login.js              → POST: Autenticación de usuarios con
                             verificación de credenciales hasheadas
  • usuarios.js           → GET/PATCH: Consulta y modificación completa
                             de perfiles (nombre, correo, foto, rol,
                             contraseña). Validación de clave maestra
                             para cambios de rol de administradores.
  • usuarios-nuevo.js     → POST: Creación de usuarios ilimitados
                             usando service_role de Supabase para
                             insertar en auth.users y public.usuarios.
  • perfil.js             → GET/PATCH: Autogestión del perfil del
                             usuario logueado.
  • clave.js              → POST: Verificación de la contraseña maestra
                             (galletas.oreo) para operaciones protegidas.
  • usuario-pin.js        → POST/PATCH: Gestión de PINs de acceso
                             rápido para el punto de venta.

BASE DE DATOS:
  • Supabase PostgreSQL con RLS (Row Level Security) configurado
  • Sincronización en tiempo real vía WebSockets / Supabase Realtime
  • Canal de presencia: "presencia-usuarios"
  • Canal de broadcast: sincronización de cambios de estado entre
    todas las sesiones activas (PC y Móvil)
  • Cache-busting implementado con timestamps en queries

SEGURIDAD:
  • Contraseñas hasheadas con scrypt (nunca almacenadas en texto plano)
  • Tokens JWT de Supabase para autenticación
  • RLS en tablas sensibles (usuarios)
  • Clave maestra separada para operaciones críticas
  • Validaciones server-side en todas las APIs
